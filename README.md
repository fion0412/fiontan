# Northstar AI

A responsive landing page for an AI services studio focused on training, automation, and AI tools.

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Supabase setup

1. Create a Supabase project.
2. Run `supabase/schema.sql` in the SQL editor.
3. Add your project URL and anon key to `app.js`, then replace the commented fetch hook with the provided request.

The included schema supports public lead submissions and featured tool catalogue reads with row-level security enabled.
